# Security and privacy

Sentinel is an educational prototype, not a secure records system. Do not use real association, owner, engineering, legal, or building-official records.

- Never commit API keys, credentials, personal information, source notices, or `.sentinel/` state.
- The optional external model adapter is disabled unless the operator selects it and confirms the source is synthetic or public. Do not send confidential records to an external model.
- Report suspected vulnerabilities privately to the repository owner. Do not include sensitive source documents in an issue.
- No external communications, filings, or automated approvals are supported.
